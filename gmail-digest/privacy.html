gmail-digest プライバシーポリシー

制定日: 2026-10-20

利用者

gmail-digest は開発者本人だけが使う個人用ツールです。第三者には提供していません。

取得する情報

Google の https://www.googleapis.com/auth/gmail.readonly スコープで、利用者本人の Gmail のメール（ヘッダーと本文）を読み取ります。メールの送信、変更、削除は行いません。

利用目的

取得したメールは、受信メールを分類してダイジェストを作るためだけに使います。

保存と外部への送信

  • 認証情報と処理の状態は、利用者本人の端末にだけ保存します。
  • 分類のため、1通ごとに差出人・件名・本文の先頭300文字だけを TypeSafe AI の API に送ります。本文の全文、宛先、メッセージ ID は送りません。
  • できあがったダイジェスト（差出人、件名、判定の理由）は、利用者本人の Discord チャンネルに Webhook で投稿します。
  • 上記以外の第三者に、取得した情報を販売、提供、共有することはありません。
  • Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス権を取り消せます。

お問い合わせ

GitHub Issues で受け付けます。

Privacy Policy (English)

Effective: 2026-10-20

  • gmail-digest is a personal tool used only by its developer. It is not offered to third parties.
  • It reads the user's own Gmail messages with the gmail.readonly scope. It never sends, modifies, or deletes mail.
  • Messages are used only to classify incoming mail and produce a digest.
  • Credentials and processing state are stored only on the user's own machine.
  • For classification, only the sender, subject, and the first 300 characters of the body of each message are sent to the TypeSafe AI API. Full bodies, recipients, and message IDs are not sent.
  • The resulting digest (sender, subject, and reason) is posted to the user's own Discord channel via a webhook.
  • Apart from the above, data is never sold, transferred, or shared with third parties.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from your Google Account permissions.
  • Contact: GitHub Issues.
